A preset is a named set of exclude and include patterns that jobs can share. Patterns are rclone filter rules. @eaDir/** matches that directory at any depth, including the top of the synced folder. A leading slash anchors to the top instead. Avoid a leading **/: it requires at least one directory in front of the name, so it misses the one at the top.
